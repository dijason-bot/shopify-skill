# 首次开发工具验证

同一示例文件的两次 revision 分别返回 INVALID 和 VALID。该证据支持复用本地检查流程，店铺买家路径与订单链路需要独立验收。[^1]

置信度指对项目底稿的归纳。具体政策、版本、费用或本店启用状态须按实际任务复核。
