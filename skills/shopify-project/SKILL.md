# Shopify 项目技能

1. 页面开发、主题改版、体验测试、SimGym、上线或回滚，先读 [页面开发与体验验证](../shopify-page-delivery/SKILL.md)。其他问题按实际入口路由。后台功能和配置读 [商家地图](references/merchant.md)。主题、应用、API、扩展和 CLI 读 [开发地图](references/development.md)。定制窗饰、支付、样品复购和广告读 [业务手册](references/window-coverings.md)。新品发布、套餐资格、迁移或版本变化读 [更新手册](references/updates.md)。
2. 明确店铺、市场、套餐、地点、渠道、币种、主题及 API 版本中与任务相关的条件。能从现有配置、代码或证据中读出的信息直接核实，缺失项记为待验证。商业判断标明使用的日期、时区和口径。
3. 查当前 Shopify 官档。商家流程以 Help Center、套餐说明和商家更新日志为入口。开发以 Shopify.dev、带版本的 schema、开发更新日志为入口。能用官方 Shopify AI Toolkit 时，用它查证并校验 Liquid、GraphQL 或扩展代码。没有该工具时，使用带版本的参考页、CLI、本地检查与测试店。
4. 给出最匹配的实现入口和一套可执行步骤。先核实 Shopify 原生功能、现有主题或已装应用覆盖到哪里，再决定配置、扩展、第三方应用或自建集成。改动前记录原值、现有实现和验证办法。涉及已发布主题、支付、邮件等正式运营动作时，按用户授权操作。
5. 以买家、商家后台和外部渠道中与任务相关的结果验收。记录样例、快照、测试订单或请求结果。把事实、推断和本店验证状态写清楚。对可复用的新发现更新对应参考文件。

执行结果按 [LLM Wiki](../../wiki/index.md) 约定写入，相关原始记录与长期结论互相链接。
